# AGENTS.md — Unslop UI Rules

Локальный свод правил для всего UI в этом репозитории. Он обязателен для любого
изменения фронтенда (`src/**`). Цель — интерфейс, который выглядит и ощущается как
нативное системное приложение (Linear / Raycast / Arc), а не как сгенерированный
「AI-дизайн」.

Стек сознательно скучный: **vanilla HTML + CSS + JS**, без фреймворков, без
сборщика, без UI-библиотек. Всё, что можно сделать на CSS, делается на CSS.

---

## 1. Запрещённый «AI-slop»

Нельзя добавлять:

- фиолетово-синие и «магические» градиенты (в том числе `linear-gradient` на
  карточках, кнопках, фоне, тексте);
- тяжёлые WebGL-шейдеры, canvas-анимации, частицы, aurora/mesh-фоны;
- `backdrop-filter: blur(...)` и «стеклянные» панели;
- пустые декоративные блоки (абстрактные круги, блобы, орбы, «glow»);
- `box-shadow` с цветным свечением, неоновые обводки, glow-радиусы;
- эмодзи в качестве иконок интерфейса;
- скругления больше `12px` у карточек и `8px` у контролов;
- кричащие акцентные заливки целых кнопок, если это не единственное главное
  действие на экране;
- маркетинговые заголовки, «✨», «🚀», заглавные буквы в каждом слове;
- placeholder-контент, «lorem ipsum», фейковые метрики в продакшене.

Иконки — только инлайновый SVG, `stroke: currentColor`, `stroke-width: 1.5`,
размер 14–18 px, без заливок и без скруглённых «мультяшных» форм.

## 2. Палитра (единственная разрешённая)

| Токен              | Значение                          | Использование                          |
| ------------------ | --------------------------------- | -------------------------------------- |
| `--bg`             | `#0B0C0E`                         | фон окна                               |
| `--surface`        | `#111215`                         | карточки, панели, инпуты               |
| `--surface-hover`  | `#181A1F`                         | ховер поверхностей                     |
| `--surface-active` | `#1E2026`                         | нажатое состояние                      |
| `--border`         | `rgba(255,255,255,0.08)`          | все границы, разделители               |
| `--border-hover`   | `rgba(255,255,255,0.16)`          | ховер/фокус границы                    |
| `--text`           | `#EDEDEF`                         | основной текст                         |
| `--text-dim`       | `#8A8F98`                         | вторичный текст                        |
| `--text-faint`     | `#5F636B`                         | третичный текст, подписи               |
| `--accent`         | `#FF0033`                         | **только** активный статус/индикатор   |
| `--accent-soft`    | `rgba(255,0,51,0.12)`             | подложка активного индикатора          |

Красный `#FF0033` — функциональный маркер YouTube. Он допустим только в:
индикаторе `Active`, точке текущих обоев, тонкой полоске активной карточки.
Кнопки, ссылки, фокус-ринги, чекбоксы — монохромные.

## 3. Типографика и числовые метрики

- UI-шрифт: `"Segoe UI Variable Text", "Segoe UI", system-ui, -apple-system, sans-serif`.
- Моноширинный: `"Cascadia Code", "Cascadia Mono", "SF Mono", ui-monospace, Consolas, monospace`.
- Базовый размер 13 px, межстрочный 1.45. Заголовки 15–18 px, вес 600.
- Микро-подписи: 10 px, `letter-spacing: 0.08em`, `text-transform: uppercase`, цвет `--text-faint`.
- Все числа (RAM, CPU, FPS, разрешение, качество, время) — моноширинный шрифт с
  `font-variant-numeric: tabular-nums`. Числа не «прыгают» при обновлении.
- Никаких `font-weight: 900`, никаких декоративных шрифтов.

## 4. Движение

- Разрешены только `transform` и `opacity` (плюс `color`, `background-color`,
  `border-color` для состояний).
- Длительность `150–220 ms`, кривая `cubic-bezier(0.2, 0, 0, 1)` (токен `--ease`).
- Ховер: смена фона/границы, максимум `translateY(-1px)`. Нажатие: `scale(0.985)`.
- Запрещены `animation` на `width`, `height`, `top`, `left`, `filter`, `box-shadow`,
  бесконечные декоративные лупы.
- Допустимые лупы: спиннер загрузки и пульс точки `Active` (только `opacity`).
- Когда окно скрыто/свёрнуто в трей, **все** анимации и переходы ставятся на
  паузу: `body.ui-paused *, body.ui-paused *::before, body.ui-paused *::after {
  animation-play-state: paused !important; transition: none !important; }`.
  Класс вешается на `visibilitychange` (и на `pagehide`).
- Уважать `prefers-reduced-motion: reduce` — отключать анимации.

## 5. Композиция

- Плотная сетка 8 px, радиусы: карточки `10px`, контролы `7px`, пилюли `999px`.
- Границы `1px solid var(--border)`, ховер — `var(--border-hover)`. Никаких
  двойных рамок и «стеклянных» слоёв.
- Одна карточка = одна задача. Заголовок секции слева, действие справа.
- Кнопки: высота 32–34 px, иконка + текст, `gap: 6px`. Primary — светлая
  монохромная (`#EDEDEF` фон, `#0B0C0E` текст) и только одна на экран.
  Destructive — прозрачная с красным текстом при ховере, без красной заливки.
- Инпуты и селекты — `--surface`, граница `--border`, фокус — `--border-hover`
  и `1px` внутренняя тень-обводка, без цветного ring.
- Пустые состояния — одна строка текста `--text-dim`, без иллюстраций.
- Иконки-кнопки 28×28 px, центр, `--text-dim` → `--text` при ховере.

## 6. Производительность

- Никаких зависимостей и бандлера. Один CSS-файл, один JS-файл на страницу.
- Список библиотеки рендерится одним проходом через `DocumentFragment` /
  `innerHTML` с обязательным HTML-экранированием.
- Не вешать `scroll`/`mousemove` без `{ passive: true }` и троттлинга.
- Телеметрия опрашивается не чаще 1 раза в 2 секунды.
- The wallpaper page must stay idle: no RAF loops, no timers, кроме событий
  видео; при паузе — ноль работы.
- Изображения: `loading="lazy"`, `decoding="async"`, явные `width/height`.

## 7. Доступность

- Все интерактивные элементы — `<button>`, `<input>`, `<select>` или `<a>`.
- Видимый фокус с клавиатуры: `outline: 1px solid var(--border-hover)`,
  `outline-offset: 2px` (не убирать `outline` без замены).
- `aria-label` на иконочных кнопках, `aria-live="polite"` на тостах.
- Контраст текста не ниже 4.5:1 на `--bg`/`--surface`.
- Тумблеры — настоящие `<input type="checkbox">` с `<label>`, состояние видно
  без JS.

## 8. Чек-лист перед коммитом

- [ ] Нет градиентов, blur, glow, декоративных пустых блоков.
- [ ] Красный используется только для активного статуса.
- [ ] Все метрики — mono + `tabular-nums`.
- [ ] Все переходы — `transform`/`opacity`/цвет, 150–220 ms, `--ease`.
- [ ] `body.ui-paused` останавливает все анимации.
- [ ] Нет новых зависимостей во фронтенде.
- [ ] Работает с клавиатуры, есть `aria-label`, видимый фокус.
