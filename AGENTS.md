# AGENTS.md — Black metal / zine UI rules

Локальный свод правил для всего UI приложения (`src/index.html`, `src/styles.css`,
`src/app.js`). Обязателен для любой правки фронтенда. Цель — жёсткий чёрно-белый
интерфейс с одним функциональным красным, без «AI-дизайна» и без «дашбордной»
миллиметровки.

Стек сознательно скучный: **vanilla HTML + CSS + JS**, без фреймворков, без
сборщика, без UI-библиотек. Страница обоев (`wallpaper.*`) не часть этого UI и
под эти правила не попадает.

---

## 1. Палитра

Цвета объявляются **только** переменными в `:root` файла `src/styles.css`.
В разметке, инлайновых стилях и JS хардкод цветов запрещён.

| Токен  | Значение  | Назначение |
| ------ | --------- | ---------- |
| `--bg`   | `#000000` | фон окна и поверхностей |
| `--fg`   | `#f2f2f2` | текст, рамки, инверсия |
| `--dim`  | `#9a9a9a` | вторичный текст |
| `--line` | `#333333` | разделители строк, второстепенные границы |
| `--red`  | `#e0001b` | единственный акцент |

Других цветов нет. Полупрозрачных подложек нет.

### Правило одного красного

`--red` разрешён только в пяти местах:

1. главная кнопка «Применить»;
2. активные обои / активный монитор (рамка превью, активная карточка, точка
   `Active`, метка «На экране»);
3. крест в логотипе;
4. ошибки (тост `is-error`, сообщения об ошибке);
5. видимый фокус с клавиатуры и `::selection`.

Всё остальное — `--fg`, `--dim`, `--line`, `--bg`. Кнопки «Остановить», удаление,
поиск, чекбоксы, селекты, скроллбары красными не бывают.

## 2. Шрифты

Локальные woff2 в `src/ui/fonts/`, лицензия в `src/ui/fonts/OFL.txt`, Credits в
README. Google Fonts по сети не подключается.

- **Pirata One** — только логотип и крупные заголовки (`h1`). **Только латиница.**
  Все такие заголовки строчные: `live wallpaper`, `add wallpaper`, `library`,
  `settings` и т.п. Кириллицу Pirata One набирать запрещено — в шрифте её нет.
- **JetBrains Mono** (Regular и Bold, латиница и кириллица) — весь остальной
  интерфейс: подписи, кнопки, списки, настройки, телеметрия, поля, тосты.
  Fallback — `Consolas, monospace`.
- Под каждым латинским `h1` — русская подпись в JetBrains Mono, UPPERCASE, `--dim`,
  вида `// ДОБАВИТЬ ОБОИ`.
- Числа (RAM, CPU, FPS, разрешение, качество, время) — JetBrains Mono с
  `font-variant-numeric: tabular-nums`.

Запрещены `font-weight: 900`, декоративные шрифты и заглавные буквы в латинских
заголовках.

## 3. Формы и композиция

- Рамки `2px solid var(--fg)` вокруг окна, шапки, карточек и между колонками.
  Разделители внутри карточек и списков — `1px solid var(--line)`.
- **Никаких скруглений, теней и градиентов.** `border-radius: 0`, `box-shadow: none`.
- Шапка: логотип `live✝wallpaper` строчными, крест `--red`; справа — кнопки в
  рамке `2px`. Выбранный переключатель — инверсия: фон `--fg`, текст `--bg`.
- Подписи разделов (`БИБЛИОТЕКА`, `ТЕЛЕМЕТРИЯ`, `НАСТРОЙКИ`) — плашка-инверсия:
  фон `--fg`, текст `--bg`, `padding: 2px 8px`.
- Карточка текущего видео: название UPPERCASE, строка режима (`direct · 2160p`)
  цветом `--dim`. Кнопки UPPERCASE в рамке `2px`; «Применить» — заливка `--red`.
- Библиотека: миниатюры в рамке `1px solid var(--fg)` с `filter: grayscale(1)
  contrast(1.2)`; активная — рамка `2px solid var(--red)` и миниатюра в цвете.
- Чекбоксы — настоящие `<input type="checkbox">`, квадрат `16×16`, рамка `2px
  solid var(--fg)`; отмеченный — заливка `--fg`.
- Модалки, поля, селекты, скроллбары и тосты — в той же палитре, без скруглений.
- Пустое состояние — одна строка текста `--dim`, без иллюстраций.

Иконки — инлайновый SVG, `stroke: currentColor`, `stroke-width: 1.5`, 14–18 px,
без заливки и без «мультяшных» форм. Эмодзи как иконки запрещены.

## 4. Движение

- Разрешены только `transform` и `opacity`, длительность `120–180 ms`, кривая
  `--ease: cubic-bezier(0.2, 0, 0, 1)`.
- Hover — инверсия (фон `--fg`, текст `--bg`). Нажатие — `scale(0.985)`.
- Запрещены бесконечные анимации, анимации `width/height/top/left/filter/
  box-shadow`, декоративные лупы и спиннеры с вращением. Состояние загрузки
  передаётся текстом (`…`), не анимацией.
- Когда окно скрыто в трее, `body.ui-paused` останавливает все переходы и
  анимации. Класс вешается на `visibilitychange` и `pagehide`.
- Уважать `prefers-reduced-motion: reduce`.

---

## 5. Производительность

- Никаких зависимостей и бандлера. Один CSS-файл, один JS-файл на страницу.
- Список библиотеки рендерится одним проходом через `innerHTML` с обязательным
  HTML-экранированием.
- Не вешать `scroll`/`mousemove` без `{ passive: true }` и троттлинга.
- Телеметрия опрашивается не чаще 1 раза в 2 секунды.
- The wallpaper page must stay idle: no RAF loops, no timers, кроме событий
  видео; при паузе — ноль работы.
- Изображения: `loading="lazy"`, `decoding="async"`, явные `width/height`.

---

## 6. Доступность

- Все интерактивные элементы — `<button>`, `<input>`, `<select>` или `<a>`.
- Видимый фокус с клавиатуры: `outline: 2px solid var(--red)`,
  `outline-offset: 2px`.
- `aria-label` на иконочных кнопках, `aria-live="polite"` на тостах.
- Контраст `--fg` и `--dim` на `--bg` не ниже 4.5:1. Текст на `--red` — только
  `--fg`.
- Состояние чекбокса видно без JS.

## 7. Чек-лист перед коммитом

- [ ] Цвета только из `:root`; в разметке и JS хардкода нет.
- [ ] Красный только в разрешённых пяти местах.
- [ ] Pirata One только на латинских `h1` и логотипе; кириллицы в нём нет.
- [ ] Под каждым `h1` есть русская подпись в JetBrains Mono UPPERCASE.
- [ ] Нет скруглений, теней, градиентов, blur и бесконечных анимаций.
- [ ] Все метрики — JetBrains Mono + `tabular-nums`.
- [ ] Переходы — `transform`/`opacity`/цвет, 120–180 ms, `--ease`.
- [ ] `body.ui-paused` останавливает все анимации.
- [ ] Нет новых зависимостей во фронтенде.
- [ ] Работает с клавиатуры, есть `aria-label` и видимый фокус.
